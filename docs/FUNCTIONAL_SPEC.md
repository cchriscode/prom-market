## 1. 사용자 역할과 권한

### 1.1 역할 정의

| 역할 | 코드 | 설명 |
|------|------|------|
| **Guest** | - | 비로그인 사용자. 마켓 브라우징만 가능 |
| **Buyer** | `BUYER` | 로그인 유저. 구매, 리뷰, 채팅, 즐겨찾기 가능 |
| **Seller** | `SELLER` | Buyer 권한 + Stripe Connect 연동 완료 후 프롬프트 등록/판매 가능 |
| **Admin** | `ADMIN` | 모든 권한 + 프롬프트 심사, 유저 관리, 시스템 설정 |

### 1.2 권한 매트릭스

| 기능 | Guest | Buyer | Seller | Admin |
|------|-------|-------|--------|-------|
| 마켓 브라우징 | O | O | O | O |
| 프롬프트 상세 보기 | O | O | O | O |
| 검색 | O | O | O | O |
| 프롬프트 구매 | X | O | O | O |
| 리뷰 작성 | X | O (구매한 프롬프트만) | O | O |
| 즐겨찾기 | X | O | O | O |
| 채팅 | X | O | O | O |
| 프롬프트 등록 | X | X | O | O |
| 판매 대시보드 | X | X | O | O |
| 정산 요청 | X | X | O | O |
| 프롬프트 심사 | X | X | X | O |
| 유저 관리 | X | X | X | O |

### 1.3 판매자 등급 시스템

| 등급 | 조건 | 혜택 |
|------|------|------|
| Bronze | 첫 판매 완료 | 기본 프로필, 판매 가능 |
| Silver | 누적 50건 판매 | 프로필 뱃지, 검색 가중치 +10% |
| Gold | 누적 200건 판매 | Featured 후보 우선권, 가중치 +20% |
| Diamond | 누적 1,000건 판매 + 평균 평점 4.8 이상 | 전용 프로모션, 수수료 15%로 할인 |

**등급 강등 조건**: 없음 (한 번 달성하면 유지)

## 2. 인증 시스템

### 2.1 회원가입

**경로**: `/register`

| 필드 | 타입 | 필수 | 검증 규칙 |
|------|------|------|-----------|
| 이메일 | email | O | RFC 5322 형식, 중복 불가 |
| 비밀번호 | password | O | 최소 8자, 영문+숫자 조합 |
| 비밀번호 확인 | password | O | 비밀번호와 일치 |
| 이름 | text | O | 2~30자 |
| 사용자명 | text | O | 3~20자, 영문 소문자+숫자+언더스코어, 중복 불가 |

**플로우**:
1. 폼 입력 → 클라이언트 유효성 검사
2. `POST /api/auth/register`
3. 이메일 인증 메일 발송 (추후)
4. 성공 시 자동 로그인 → 홈으로 리다이렉트

**에러 처리**:
- 이메일 중복: "이미 사용 중인 이메일입니다"
- 사용자명 중복: "이미 사용 중인 사용자명입니다"
- 비밀번호 불일치: 실시간 표시

### 2.2 로그인

**경로**: `/login`

| 방식 | 설명 |
|------|------|
| 이메일/비밀번호 | 기본 로그인 |
| Google OAuth | NextAuth 소셜 로그인 |
| GitHub OAuth | NextAuth 소셜 로그인 |

**플로우**:
1. 이메일+비밀번호 입력 또는 소셜 버튼 클릭
2. `POST /api/auth/login` 또는 OAuth 리다이렉트
3. JWT 토큰 발급 → 쿠키 저장
4. 이전 페이지로 리다이렉트 (없으면 홈)

**에러 처리**:
- 잘못된 이메일/비밀번호: "이메일 또는 비밀번호가 올바르지 않습니다"
- 소셜 로그인 실패: "소셜 로그인에 실패했습니다. 다시 시도해주세요"
- 5회 연속 실패: 5분 잠금

### 2.3 로그아웃

- `POST /api/auth/logout`
- 쿠키/토큰 삭제 → 홈으로 리다이렉트

### 2.4 세션 관리

- Access Token: 1시간 유효
- Refresh Token: 7일 유효
- 401 응답 시 자동 갱신 후 원래 요청 재시도
- 갱신 실패 시 로그인 페이지로 리다이렉트

## 3. 레이아웃과 네비게이션

### 3.1 전체 레이아웃 구조

```
┌──────────┬─────────────────────────────────┐
│          │         TopBar (56px)           │
│ Sidebar  ├─────────────────────────────────┤
│ (240px / │                                 │
│  64px)   │        Content Area             │
│          │     (max-width: 1280px)         │
│          │                                 │
│          ├─────────────────────────────────┤
│          │         Footer                  │
└──────────┴─────────────────────────────────┘
```

### 3.2 사이드바

**상태**: `isSidebarExpanded` (Zustand, localStorage persist)

| 상태 | 너비 | 표시 |
|------|------|------|
| 펼침 | 240px | 아이콘 + 라벨 |
| 접힘 | 64px | 아이콘만 (호버 시 툴팁) |
| 모바일 (<1024px) | 전체 너비 오버레이 | 햄버거 메뉴로 토글 |

**네비게이션 항목**:

```
메인 섹션:
  - 홈 (/)
  - 마켓플레이스 (/marketplace)
  - 검색 (/search)

크리에이터 섹션:
  - 프롬프트 판매 (/sell)
  - Hire (/hire)
  - 앱 빌더 (/create)

내 카테고리 (접힘 시 숨김):
  - 사용자가 최근 본/구매한 AI 모델 카테고리 자동 표시
  - 최대 5개 + "더 보기" 링크

하단 고정:
  - 채팅 (/chat)
  - [로그인 전] 로그인/회원가입 버튼
  - [로그인 후] 아바타 + 사용자명 + 판매자 등급 뱃지
```

**애니메이션**: `width` 전환 250ms ease-out

### 3.3 상단 바 (TopBar)

| 요소 | 위치 | 설명 |
|------|------|------|
| 검색 인풋 | 왼쪽 | 확장형, 엔터 시 `/search?q=...`로 이동 |
| 알림 벨 | 오른쪽 | 읽지 않은 알림 수 뱃지, 클릭 시 드롭다운 |
| 장바구니 | 오른쪽 | 아이템 수 뱃지, 클릭 시 `/cart`로 이동 |

높이: 56px, `position: sticky`, `top: 0`, `z-index: 40`

## 4. 홈페이지

**경로**: `/`

### 4.1 섹션 구성 (순서대로)

#### 4.1.1 히어로 배너 캐러셀

- 슬라이드 3~5개, 5초 자동 전환
- 각 슬라이드: 제목 + 부제 + CTA 버튼 + 배경 그라데이션
- 수동 좌우 화살표 + 하단 도트 인디케이터
- 터치 스와이프 지원 (모바일)

#### 4.1.2 Featured Prompts

- 편집팀 수동 선정 (`isFeatured: true`)
- 가로 스크롤 캐러셀 (스크롤 화살표 + 드래그)
- 카드 5개 표시, 이후 스크롤

#### 4.1.3 Trending Prompts

- 알고리즘 기반 정렬:
  ```
  Score = (7일 판매 * 0.4) + (7일 조회 * 0.2) + (즐겨찾기 * 0.2) + (평점 * 0.2)
  ```
- 1~30위 넘버링 표시
- 가로 스크롤 캐러셀

#### 4.1.4 카테고리 바로가기 그리드

- 아이콘 + 라벨 그리드
- 클릭 시 `/marketplace?category={slug}`
- 3~4행 그리드 레이아웃

#### 4.1.5 AI 모델별 인기

- 탭 전환 UI (최대 9개 모델)
- 선택된 모델에 해당하는 프롬프트를 5열 그리드로 표시
- 최대 10개

#### 4.1.6 Newest Prompts

- 최신 등록순 정렬, 최대 20개
- 5열 그리드

#### 4.1.7 이달의 인기 프롬프트

- 월간 Top 15, 넘버링 표시
- 가로 스크롤

#### 4.1.8 판매자 CTA 배너

- "프롬프트를 판매하세요 — 2분이면 시작"
- CTA → `/sell`

#### 4.1.9 Hire CTA 배너

- "전문 프롬프트 엔지니어에게 맡기세요"
- CTA → `/hire`

### 4.2 로딩 상태

- 각 섹션별 스켈레톤 UI
- 카드 스켈레톤: 1:1 비율 회색 박스 + 3줄 텍스트 shimmer
- shimmer 애니메이션: gradient sweep 1.5s loop

## 5. 마켓플레이스

**경로**: `/marketplace`

### 5.1 레이아웃

```
┌──────────┬──────────────────────────┐
│  필터    │  [ActiveFilters] [Sort ▼]│
│  패널    │                          │
│  (좌측)  │  ┌───┬───┬───┬───┬───┐  │
│  256px   │  │   │   │   │   │   │  │
│          │  │카드│카드│카드│카드│카드│  │
│          │  └───┴───┴───┴───┴───┘  │
│          │  ... (무한 스크롤)       │
└──────────┴──────────────────────────┘
```

### 5.2 필터 패널

| 필터 | 타입 | 동작 |
|------|------|------|
| AI 모델 | 체크박스 목록 | 다중 선택 가능, `?model=midjourney` |
| 프롬프트 타입 | 라디오 | IMAGE / TEXT / VIDEO, `?type=IMAGE` |
| 카테고리 | 체크박스 목록 | 다중 선택 가능, `?category=logo` |
| 가격대 | 범위 슬라이더 | Free / $1-5 / $5-10 / $10+ |
| Select 전용 | 토글 | Select 포함 프롬프트만 |

- 모든 필터는 URL 쿼리 파라미터로 동기화
- 뒤로가기/앞으로가기 시 필터 상태 유지
- 모바일: 필터 패널은 하단 시트(bottom sheet)로 열기

### 5.3 정렬 옵션

| 옵션 | 키 | 설명 |
|------|-----|------|
| 트렌딩 | `trending` | 기본값, Trending Score 기반 |
| 최신순 | `newest` | createdAt DESC |
| 인기순 | `popular` | salesCount DESC |
| 가격 낮은순 | `price-asc` | price ASC |
| 가격 높은순 | `price-desc` | price DESC |

### 5.4 프롬프트 카드 그리드

**반응형 열 수**:

| 화면 너비 | 열 수 |
|-----------|-------|
| >= 1280px | 5열 |
| >= 1024px | 4열 |
| >= 768px | 3열 |
| < 768px | 2열 |

**카드 스펙**: [6. 프롬프트 상세 참조](#61-프롬프트-카드-구성)

### 5.5 페이지네이션

- 무한 스크롤 방식
- 한 번에 20개 로드
- 스크롤 하단 도달 시 다음 페이지 자동 로드
- 로딩 중: 스켈레톤 카드 4개 표시
- 전체 결과 수 상단에 표시: "1,234개 프롬프트"

## 6. 프롬프트 상세 페이지

**경로**: `/prompt/:slug`

### 6.1 프롬프트 카드 구성 (마켓플레이스 그리드용)

```
┌──────────────────────┐
│ ┌──────────────────┐ │
│ │  이미지 (1:1)    │ │
│ │  [AI모델뱃지]    │ │
│ │         [♡ 버튼] │ │
│ │  [Select뱃지]    │ │
│ │  [워터마크]      │ │
│ └──────────────────┘ │
│ 프롬프트 제목 (2줄)  │
│ @판매자  ★4.8        │
│ $3.99  ~~$4.99~~     │
└──────────────────────┘
```

**이미지 영역**:
- `aspect-ratio: 1/1` (정사각형)
- `thumbnail` 있으면 `<img>`, 로드 실패 시 이모지 fallback
- 워터마크 오버레이: 대각선 반복 패턴, `opacity: 0.07`
- 좌상단: AI 모델 뱃지 (랭킹 있으면 순위 뱃지)
- 우상단: 즐겨찾기 버튼 (hover 시에만 표시)
- 좌하단: Select 뱃지 (해당 시)

**정보 영역**:
- 제목: `text-sm font-semibold`, 최대 2줄 (`line-clamp-2`)
- 판매자: `@username`, `text-[13px] text-muted-foreground`
- 평점: 별 아이콘 + 숫자 (소수점 1자리)
- 가격: `font-mono font-bold`, 할인 시 원가 취소선 + 할인가

### 6.2 상세 페이지 레이아웃

```
┌────────────────────────────────────────────┐
│  [← 뒤로]  카테고리 > 프롬프트 타이틀      │
├──────────────────────┬─────────────────────┤
│  이미지 갤러리       │  구매 패널          │
│  (메인 + 썸네일)     │  - 가격             │
│                      │  - Add to Cart 버튼 │
│                      │  - Select 다운로드   │
│                      │  - 보장 아이콘들     │
├──────────────────────┴─────────────────────┤
│  프롬프트 정보                              │
│  - 제목, 설명, 메타 정보                    │
│  - AI 모델, 타입, 카테고리, 단어 수          │
├────────────────────────────────────────────┤
│  리뷰 섹션                                  │
│  - 평균 평점 + 분포 바                      │
│  - 리뷰 작성 폼                             │
│  - 리뷰 목록                                │
├────────────────────────────────────────────┤
│  관련 프롬프트                               │
└────────────────────────────────────────────┘
```

### 6.3 이미지 갤러리

| 동작 | 설명 |
|------|------|
| 메인 이미지 | 프롬프트 이미지 중 첫 번째, 클릭 시 확대 모달 |
| 썸네일 목록 | 하단에 가로로 나열, 클릭 시 메인 이미지 전환 |
| 전환 애니메이션 | fade 200ms |
| 빈 이미지 | 이모지 fallback + "이미지 없음" 텍스트 |

### 6.4 구매 패널

| 상태 | 표시 내용 |
|------|-----------|
| 비로그인 | 가격 + "로그인 후 구매" 버튼 |
| 무료 프롬프트 | "무료 다운로드" 버튼 |
| 유료 + 장바구니에 없음 | "장바구니에 추가" 버튼 |
| 유료 + 장바구니에 있음 | "장바구니에 담김" (비활성) |
| Select 포함 + 구독자 | "Select로 다운로드 (N회 남음)" 버튼 |
| Select 포함 + 미구독 | "Select 구독 필요" (비활성) |
| 이미 구매함 | "프롬프트 보기" 버튼 → 프롬프트 텍스트 표시 |

**보장 아이콘**:
- "검증된 프롬프트" (심사 통과)
- "즉시 접근" (결제 후 바로 사용)
- "안전한 결제" (Stripe 처리)

### 6.5 프롬프트 텍스트 접근 규칙

| 조건 | 접근 |
|------|------|
| 미구매 | 프롬프트 텍스트 비공개, 설명/예시 이미지만 표시 |
| 구매 완료 | `GET /api/prompts/:id/content` → 프롬프트 전문 표시 |
| Select 다운로드 | 동일하게 전문 접근 가능 |
| 무료 | "다운로드" 클릭 후 접근 가능 (로그인 필요) |

### 6.6 에러 처리

- 존재하지 않는 slug → 404 페이지
- 비활성/심사중 프롬프트 → "이 프롬프트는 현재 이용할 수 없습니다"
- 네트워크 에러 → 재시도 버튼

## 7. 프롬프트 등록 (판매)

**경로**: `/sell`
**권한**: Seller만 (Buyer는 Stripe Connect 온보딩 유도)

### 7.1 멀티스텝 폼

#### Step 1: 기본 정보

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| AI 모델 | select | O | 30+ 모델 중 선택 |
| 프롬프트 타입 | radio | O | IMAGE / TEXT / VIDEO |
| 카테고리 | select | O | 70+ 카테고리 중 선택 |

#### Step 2: 프롬프트 작성

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 제목 | text | O | 5~100자 |
| 설명 | textarea | O | 20~2000자 |
| 프롬프트 텍스트 | textarea | O | 10~10000자, 변수는 `[대괄호]`로 |
| 테스트 프롬프트 | textarea | O | 변수가 채워진 완성 버전 1개 |

**변수 자동 감지**: `[variable]` 형식 입력 시 하이라이트 표시

#### Step 3: 예시 출력물

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 이미지/비디오 | file upload | O (최소 1개) | 최대 9개, 이미지: JPG/PNG/WebP 10MB 이하, 비디오: MP4 50MB 이하 |
| 썸네일 선택 | radio | 자동 | 첫 번째 이미지가 기본 썸네일, 변경 가능 |

**업로드 UX**:
- 드래그 앤 드롭 지원
- 업로드 프로그레스 바
- 업로드 완료 후 미리보기
- 순서 드래그로 변경 가능

#### Step 4: 가격 설정

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 무료 여부 | toggle | O | 무료 선택 시 가격 입력 비활성 |
| 가격 | number | 조건부 | $0.99 ~ $49.99 |
| 할인율 | number | X | 0~90% |
| Select 포함 | toggle | X | Select 구독자에게 무료 다운로드 허용 |

**수수료 미리보기**: 입력 가격 옆에 "예상 수익: $X.XX (수수료 20% 차감)" 실시간 계산

#### Step 5: 검증 & 제출

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 검증 링크 | URL | 모델별 상이 | Midjourney: 생성 링크 등 |
| 약관 동의 | checkbox | O | 체크 필수 |

**제출 후**:
- 상태: `PENDING` (심사 대기)
- "프롬프트가 제출되었습니다. 심사 결과는 15분~36시간 내에 알려드립니다."
- 폼 데이터 + localStorage 초기화

### 7.2 스텝 인디케이터

- 현재 스텝: 강조 (primary)
- 완료 스텝: 클릭으로 이동 가능
- 미래 스텝: 비활성, 클릭 불가
- 접힘 시 번호만 표시, 펼침 시 라벨도 표시

### 7.3 자동 저장

- `zustand/persist`로 localStorage에 자동 저장
- 브라우저 새로고침/재방문 시 이전 입력 유지
- 제출 완료 또는 수동 리셋 시 삭제

### 7.4 프롬프트 수정

**경로**: `/sell/:promptId/edit`
**권한**: 해당 프롬프트의 판매자만

- 기존 데이터 프리필
- Step 1~4 필드 수정 가능
- 재심사 필요 여부: 가격/설명만 변경 시 불필요, 프롬프트 텍스트/이미지 변경 시 재심사

## 8. 구매 플로우

### 8.1 장바구니

**경로**: `/cart`

| 기능 | 설명 |
|------|------|
| 추가 | 프롬프트 상세 → "장바구니에 추가" 클릭 |
| 삭제 | 개별 삭제 + 전체 삭제 |
| 수량 | 프롬프트는 1개만 (중복 추가 불가) |
| 가격 계산 | 할인가 적용 → 합계 표시 |
| 영속성 | `zustand/persist` → localStorage |

**장바구니 위젯 (사이드바)**:
- TopBar 장바구니 아이콘 클릭 시 사이드 패널(선택) 또는 `/cart` 이동
- 아이템 수 뱃지

### 8.2 결제 (Stripe Checkout)

**플로우**:
1. `/cart` → "결제하기" 클릭
2. `POST /api/checkout` → Stripe Checkout Session 생성
3. Stripe 결제 페이지로 리다이렉트
4. 결제 완료 → `success_url`로 리다이렉트
5. Webhook → `Purchase` 레코드 생성 + 프롬프트 접근 권한 부여

**지원 결제 수단**:
- 신용/체크카드
- (향후) 카카오페이, 토스페이

**에러 처리**:
- 결제 취소: 장바구니 유지, "결제가 취소되었습니다" 메시지
- 결제 실패: "결제에 실패했습니다. 다시 시도해주세요"
- Webhook 실패: 재시도 큐 (3회)

### 8.3 무료 프롬프트 다운로드

**플로우**:
1. 프롬프트 상세 → "무료 다운로드" 클릭
2. 로그인 체크 (미로그인 시 로그인 페이지로)
3. `Purchase` 레코드 생성 (amount: 0, method: INDIVIDUAL)
4. 프롬프트 텍스트 접근 가능

### 8.4 구매 내역

**경로**: `/account/purchases`

| 표시 항목 | 설명 |
|-----------|------|
| 프롬프트 제목 | 상세 페이지 링크 |

## 19. 관리자 기능

### 19.1 프롬프트 심사

**경로**: `/admin/review` (별도 관리자 페이지)

#### 심사 플로우

1. 판매자가 프롬프트 제출 (`PENDING`)
2. 관리자 심사 대기열에 표시
3. 관리자가 프롬프트 내용 + 예시 출력물 + 테스트 프롬프트 검토
4. 승인 → `ACTIVE` + 마켓에 노출
5. 거절 → `REJECTED` + 사유 입력 → 판매자에게 알림

#### 거절 사유 (사전 정의)

| 코드 | 사유 | 설명 |
|------|------|------|
| `NO_USE_CASE` | 유스케이스 없음 | 구매 가치 불충분 |
| `TOO_NARROW` | 범위 너무 좁음 | 변수를 추가하여 일반화 필요 |
| `INCONSISTENT` | 스타일 불일관 | 예시 출력물 간 스타일 차이 |
| `LOW_QUALITY` | 낮은 품질 | 오탈자, 의미불명 |
| `TEST_MISMATCH` | 테스트 불일치 | 심사팀 결과가 예시와 다름 |
| `TOO_SIMPLE` | 너무 단순 | 제목만 봐도 유추 가능 |
| `DUPLICATE` | 중복 | 기존 프롬프트와 유사 |
| `NSFW` | NSFW | 성인/폭력 콘텐츠 |
| `TOS_VIOLATION` | 이용약관 위반 | AI 모델 규칙 우회 |
| `PLAGIARISM` | 표절 | 공개 출처에서 복사 |
| `AI_GENERATED` | AI 대량 생성 | 자동 생성 의심 |
| `LINK_MISMATCH` | 검증 링크 불일치 | 제출 내용과 검증 링크 불일치 |

#### 자동 검사 (AI 보조)

- 텍스트 유사도: 기존 프롬프트와 코사인 유사도 > 0.85 → 자동 플래그
- NSFW 필터: 키워드 + AI 분류기
- 품질 점수: 프롬프트 길이, 변수 수, 문법 검사

### 19.2 사용자 관리

| 기능 | 설명 |
|------|------|
| 유저 목록 | 검색, 역할 필터 |
| 역할 변경 | Buyer ↔ Seller, Admin 부여 |
| 계정 정지 | 사유 + 기간 설정 |
| 판매자 등급 수동 조정 | 특수 프로모션 용 |

**HTTP 상태 코드**:

| 코드 | 사용 |
|------|------|
| 200 | 성공 |
| 201 | 생성 성공 |
| 400 | 잘못된 요청 (유효성 검사 실패) |
| 401 | 인증 필요 |
| 403 | 권한 없음 |
| 404 | 리소스 없음 |
| 409 | 충돌 (중복 등) |
| 429 | 요청 제한 초과 |
| 500 | 서버 에러 |
